# Supplementary Figure S3 permutation update

The submission version extends the original six-panel CellOracle summary with two formal control panels:

- Panel G: paired observed-versus-randomized state-shift differences, evaluated with 10,000 paired-label permutations.
- Panel H: lesion-side versus internal-control-side mean-vector directionality, evaluated with 10,000 group-label permutations.

The permutation workflow uses fixed seed `20240817` and the source script `scripts/permutation_test_celloracle.py`. The assembled figure is generated by `scripts/manuscript_figures/build_figS3_with_permutation_panels.py`.

These controls test simulated perturbation structure relative to randomized network controls. They do not constitute biological replication or experimental validation.
