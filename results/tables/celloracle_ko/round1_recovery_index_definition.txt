Approx. Recovery Index / Approx. RI definition

Approx. RI is a study-defined cosine-similarity-based alignment metric used to summarize CellOracle in silico perturbation direction.

Reference vector:
  lesion-to-internal-control reference vector = centroid_internal-control - centroid_lesion

Approx. RI:
  Approx. RI = cos(perturbation vector, lesion-to-internal-control reference vector)

Interpretation:
- Higher mean shift indicates a larger simulated state-space displacement.
- Higher Approx. RI indicates stronger directional alignment between the simulated perturbation vector and the lesion-to-internal-control reference vector.
- Random perturbation controls were used as negative-control context for the simulated perturbation outputs.

Boundary:
- Approx. RI is not a CellOracle official standard metric.
- Approx. RI is not a clinical recovery metric.
- CellOracle outputs are computational in silico perturbation results, not experimental perturbation evidence.
