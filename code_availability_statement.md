The analysis code supporting this study is available at https://github.com/vermouth-SVG/fcdii-astrocyte-regulon-perturbation. The repository contains analysis scripts, configuration files, processed outputs, figure/table generation scripts and reproducibility notes. The repository is organized to support layered reproduction of manuscript tables, figures and processed analyses, but it does not claim a single-command full rerun of all raw-data and database-dependent steps.
