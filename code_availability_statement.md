Project name: FCD II astrocyte regulon and in silico perturbation analysis. Project home page: https://github.com/vermouth-SVG/fcdii-astrocyte-regulon-perturbation. The repository contains the analysis scripts, configuration files, processed outputs, figure-generation scripts, the submitted manuscript, the main and supplementary figures, and the supplementary tables. The original analyses were run in a Linux virtual machine using the documented Docker images. Full upstream reruns additionally require the public datasets and external cisTarget resources. Code is released under the MIT License; third-party data and resources remain governed by their source licenses. The repository supports layered reproduction but does not claim a single-command, bitwise-identical rerun of every raw-data- and database-dependent step.
