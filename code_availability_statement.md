The code supporting this study is available at https://github.com/vermouth-SVG/fcdii-astrocyte-regulon-perturbation. The repository contains analysis scripts, configuration and environment notes, processed summary tables, figure/table generation materials, and reproducibility audit files. Large raw single-cell matrices, large external databases, and bulky intermediate computational objects are not redistributed with the code repository and should be obtained from the original public data repositories or database providers. The repository is organized to support layered reproduction of manuscript tables, figures, and processed analyses, but it does not claim a single-command full rerun of all raw-data and database-dependent steps. A Zenodo DOI will be added if the repository is archived.
