# Release notes - 2026-10-25 submission version

This update brings the repository to the version of the manuscript submitted to BMC Genomics in October 2026.

## Manuscript and submission files

- `Manuscript.docx` replaced with the 2026-10-25 submission version (single-nucleus reanalysis; NFE2L2 and THRB as the two leading regulatory programs; five supporting candidates; three-part abstract; no tracked changes and no comments).
- `Cover_Letter.docx` added.
- `Additional_file_1.zip` added: Supplementary Figures S1-S6 (TIFF, 600 dpi) and figure legends.
- `Additional_file_2.zip` added: Supplementary Tables ST01-ST09 (XLSX) and table legends.
- `Supplementary_Tables_ST01_ST09_submission_ready.xlsx` replaced with the current ST01-ST09 workbook.

## Figures

- Main Figures 1-5 replaced with the submitted TIFF files (170 mm wide, BMC Genomics full-page width) and matching PNG and PDF exports.
- Supplementary figures renumbered to S1-S6; the former Supplementary Figure S7 was retired.
- Vector SVG copies of the main figures removed, because the submitted figures were rebuilt and only raster outputs exist for this version.

## Repository documents

- `README.md`, `MANIFEST.md`, `CITATION.cff`, `data_availability_statement.md`, `code_availability_statement.md` and `file_manifest.csv` updated to the current manuscript title, study framework and file set.
- The former `Supplementary_Figures_S1_S7_preview_not_for_submission.docx` review package removed.

## Unchanged

- Analysis scripts (`scripts/`) and processed summaries (`results/tables/`) remain the 2026-09-10 analysis snapshot.
- Large raw matrices, controlled-access data, cisTarget databases, motif annotation files and Docker images are still not redistributed.
